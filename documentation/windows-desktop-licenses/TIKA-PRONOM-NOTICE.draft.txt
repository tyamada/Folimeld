IPTC scope clarification (draft)

The fixed Tika source identifies July 2010 IPTC Photo Metadata descriptions
in org/apache/tika/metadata/IPTC.java and Photoshop.java. Those Java files
are not part of the five-file Qt MIME-data source subset prepared here.
IPTC-branded NewsML/other MIME identifiers in the XML are not, by that name
alone, evidence that the 2010 Photo Metadata descriptions are included.
The original upstream acknowledgement is retained pending final scope review.
The current IPTC standard's CC BY 4.0 licence is not asserted to relicense
those historical descriptions. Full historical terms are kept as reference
evidence, not imposed on Folimeld or on every MIME definition.
