# Folimeld 0.3.5 AlmaLinux 9 amd64向け公開案

未公開の準備稿。添付物の最終確認と版確定が完了するまで公開しない。

AlmaLinux 9.8のWSL2／WSLg環境で検証したx86_64向けRPM候補です。ARM64、AlmaLinux 10、通常のデスクトップ環境は今回の検証対象に含みません。

導入例（公開後の配布ファイルを使用）:

```sh
sha256sum -c SHA256SUMS.txt
sudo dnf install ./folimeld-0.3.5-5.alma9_8.x86_64.rpm
folimeld
```

検証した操作は、日本語PDF表示、回転・Undo/Redo・ページ移動・白紙挿入削除、日本語名での別名保存と再読込、暗号化PDF、PNG取込み、IBus/Mozc入力です。非公開0.3.3候補からの更新、設定3項目の保持、削除再導入、独立したXDG/D-BusでのGIO起動も確認しました。最小依存installrootでは一般ユーザー相当でoffscreen起動を確認しています。

公開Ubuntu/Debian 0.3.4からの移行、通常ファイルマネージャー操作、独立した最小WSLのブート、任意の既存設定は未検証です。推奨日本語フォントを省略した最小依存試験は、日本語GUIの表示確認とは異なります。

RPM、対応するFolimeldソースZIP、パッケージとソースの対応記録、第三者告知、依存ソースの収集資料とチェックサムを添付する予定です。依存ソース集合とwheelビルド来歴の確認は継続中であり、この稿は添付物の完全性や公開準備の完了を表明するものではありません。

RPMは未署名です。SHA256SUMS.txtはファイルの照合用であり、配布者を認証する署名ではありません。

LibTIFFのLZW実装には、カリフォルニア大学バークレー校で開発されたソフトウェアが含まれます。詳細は同梱のLibTIFF-LZW告知を参照してください。
