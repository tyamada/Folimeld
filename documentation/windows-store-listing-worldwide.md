## German (`de-DE`)

### Short description
PDF-Seiten per Miniaturansicht intuitiv neu anordnen, drehen, einfügen und löschen. Erstellt auch PDFs aus Bilderordnern.

### Description
Folimeld ist eine Desktop-App zum einfachen Organisieren von PDF-Seiten anhand von Miniaturansichten. Ordnen Sie Seiten neu an, korrigieren Sie die Ausrichtung oder fügen Sie Seiten aus anderen PDF-Dateien ein. Alle Dokumente werden ausschließlich lokal auf Ihrem Gerät verarbeitet; weder PDFs noch Bilder werden zur Bearbeitung an Entwicklerserver gesendet.

Wählen Sie mehrere Seiten aus, um sie gemeinsam zu verschieben, zu drehen oder zu löschen. Rückgängig (Undo) und Wiederholen (Redo) bleiben auch nach dem Speichern verfügbar.

Erstellen Sie neue PDFs aus Ordnern mit JPEG-, PNG-, BMP-, TIFF- oder WebP-Bildern. Sortieren Sie nach Name oder Datum, schließen Sie unerwünschte Bilder aus und wählen Sie Originalgröße oder A4. Mehrseitige TIFF-Dateien werden ebenfalls unterstützt.

In den Dokumenteigenschaften lassen sich PDF-Version, Seitenlayout, Bindungsrichtung (inkl. Rechtsbindung und Deckblatt) sowie ein Passwort zum Öffnen festlegen oder entfernen.

### Product features
- PDF-Seiten per Miniaturansicht neu anordnen
- Mehrere Seiten gleichzeitig verschieben, drehen oder löschen
- Andere PDFs oder leere Seiten einfügen
- Rückgängig und Wiederholen auch nach dem Speichern
- PDFs aus Bilderordnern erstellen (JPEG, PNG, BMP, TIFF, WebP)
- PDF-Version, Seitenlayout, Rechtsbindung und Deckblatt festlegen
- Passwort zum Öffnen festlegen und entfernen
- Native Unterstützung für Windows 11 x64 und ARM64 (z. B. Copilot+ PC)

### What's new (1.0.7.0)
- Vollständige Übersetzung der Benutzeroberfläche auf Deutsch, Spanisch, Französisch und Portugiesisch (inkl. Passwort- und Beispiel-PDF-Funktionen).
- Erweiterung der weltweiten Verfügbarkeit im Microsoft Store.

## Spanish (`es-ES`)

### Short description
Organiza páginas PDF con miniaturas: reordena, gira, inserta y elimina páginas, o crea PDFs desde carpetas de imágenes.

### Description
Folimeld es una aplicación de escritorio para organizar páginas PDF de forma intuitiva mediante miniaturas. Cambie el orden de las páginas, corrija su orientación o inserte páginas desde otros archivos PDF. Todos los documentos se procesan únicamente en su dispositivo; no se envían PDF ni imágenes a servidores del desarrollador.

Seleccione varias páginas para moverlas, girarlas o eliminarlas a la vez. Deshacer (Undo) y Rehacer (Redo) siguen disponibles incluso después de guardar.

Cree nuevos PDF a partir de carpetas con imágenes JPEG, PNG, BMP, TIFF o WebP. Ordene por nombre o fecha, excluya las imágenes innecesarias y elija tamaño original o A4. También admite archivos TIFF multipágina.

En las propiedades del documento puede configurar la versión PDF, el diseño de página, la dirección de encuadernación (incluida encuadernación derecha y portada) y establecer o quitar la contraseña de apertura.

### Product features
- Reordenar páginas PDF mediante miniaturas
- Mover, girar o eliminar varias páginas a la vez
- Insertar otros PDF o páginas en blanco
- Deshacer y Rehacer incluso después de guardar
- Crear PDF desde carpetas de imágenes (JPEG, PNG, BMP, TIFF, WebP)
- Configurar versión PDF, diseño de página, encuadernación derecha y portada
- Establecer y quitar contraseña de apertura
- Soporte nativo para Windows 11 x64 y ARM64 (Copilot+ PC, etc.)

### What's new (1.0.7.0)
- Traducción completa de la interfaz en alemán, español, francés y portugués (incluidas las funciones de contraseña y PDF de ejemplo).

## Simplified Chinese (`zh-CN`)

### Short description
通过缩略图直观整理 PDF 页面：排序、旋转、插入、删除，并支持从图片文件夹创建 PDF。

### Description
Folimeld 是一款可通过缩略图轻松整理 PDF 页面的桌面应用。您可以调整页面顺序、校正方向或从其他 PDF 插入页面。所有文档仅在您的设备本地处理，不会将 PDF 或图片上传到开发者服务器。

支持多选页面一次进行移动、旋转或删除，保存后仍可使用撤销（Undo）和重做（Redo）。

可从包含 JPEG、PNG、BMP、TIFF 或 WebP 的图片文件夹创建新 PDF，按名称或日期排序、排除不需要的图片，并选择适应图片大小或 A4 页面尺寸，同时支持多页 TIFF。

在文档属性中可设置 PDF 版本、页面布局、装订方向（含右装订与封面设置），并支持设置或移除打开密码。

### Product features
- 通过缩略图预览重新排列 PDF 页面
- 多选页面批量移动、旋转或删除
- 插入其他 PDF 或空白页
- 保存后仍可用的撤销与重做
- 从图片文件夹创建 PDF（JPEG、PNG、BMP、TIFF、WebP）
- 设置 PDF 版本、页面布局、右装订与封面
- 设置或移除打开密码
- 原生支持 Windows 11 x64 与 ARM64（Copilot+ PC 等）

### What's new (1.0.7.0)
- 补全德语、西班牙语、法语和葡萄牙语界面翻译，并面向全球 Microsoft Store 扩大发布范围。
- 内置 Microsoft Store 更新检查与更新按钮，以及支持者徽章界面。
