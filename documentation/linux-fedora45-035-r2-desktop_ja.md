# Fedora 45 revision2のIME・GIO・ライセンス画面

2026-11-13。[revision2候補](linux-fedora45-035-r2_ja.md)の新ELFを、許可済み専用Testの一般ユーザー・新規XDG/D-Busセッションで確認した。Fedora版は未公開。

## 確認結果

- GIO：日本語・空白を含む `日本語 パス/関連付け 試験.pdf` を `gio open` で開いた。終了コード0、アプリタイトルと3ページの描画を確認した。MIME関連付けは専用XDG設定に限定した。元PDFと試験コピーのSHA-256は不変。
- IME：Qtファイル選択ダイアログで、Mozcの日本語入力モードへ切り替え、`nihongo` → `にほんご` → `日本語` の変換・確定を確認した。試験後はキャンセルし、ファイルを開いたり保存したりしていない。
- ライセンス：Folimeld本文に加え、ICU-73.2・LibTIFF-LZW・Fedora OS・MuPDFソース告知・Qt追加ライセンス・Qtソース告知の各タブを実際に表示し、文書が描画されることを確認した。大きなQt告知も表示できた。全告知の法的な適合認定とは区別する。

実行ELF SHA-256は `a87ae589b6d5dad22ea7d2a246d0764ec360b2439c47768a17970cc83da5680f`。実行環境はWSLg X11で、完全なLinuxデスクトップやファイルマネージャーのダブルクリック試験ではない。GUI・IBusは既存の試験ツールを使用しており、最小依存導入とは区別する。

## 試験手順の修正と終了処理

初回GIOではアプリの描画後、試験スクリプトがプロセス名の部分一致を使ったため、同じ専用プロファイルの結果記録プロセスも終了した。既存環境のプロセスは対象になっていない。この回の終了値は合格根拠にせず、新しい `version035-r2-desktop-gio2-20261113` で標準出力をファイルへ分離して再試験した。終了処理も実行ファイル名・UID・専用プロファイルを照合する形へ修正した。

IBusのエンジン設定コマンドは終了値1を返した。待機だけを増やしても同じであったため、現在のエンジンを別途照会し、終了値0・`mozc-jp` を確認したうえで実入力を検証した。初期状態は直接入力だったので、日本語入力モードへ切り替えてから変換した。失敗記録とセッション警告は保持した。

完了後は今回の各専用プロファイルに属するプロセスをUID・環境変数で確認して終了した。システムのWSL設定、グローバルなMIME設定、暗号ポリシーは変更していない。
