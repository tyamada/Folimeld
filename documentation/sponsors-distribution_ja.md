# GitHub Sponsors案内の配布方式別対応

[English](sponsors-distribution.md)

次版向けのソース変更です。公開済みパッケージは変更しません。
Linuxの動作を維持し、FreeBSD・NetBSD・OpenBSDも同じ案内画面を利用します。
Windowsは非MSIX・非凍結のuv専用プロファイルが有効な場合に限定し、通常のソース起動では表示しません。
Windows ARM64 uvの依存準備・実機受入は別の未完了作業です。

HomebrewではFormulaがmain.pyと同じアプリ領域へlaunch_homebrew.pyを追加し、
bin/folimeldの既存シェルラッパーで、専用Pythonから同ファイルを起動する必要があります。
これがrun(distribution="homebrew")を呼びます。通常のmain.py・凍結macOSアプリでは有効になりません。
この識別情報は表示条件であり、インストール元の真正性を保証する仕組みではありません。

次のHomebrewソース公開時にURL・版・SHA-256とあわせてFormulaを更新します。
変更箇所の例は英語版を参照してください。既存ラッパー内の起動ファイル名を変更し、
libexecの専用Pythonと引数転送は維持します。旧0.3.3アーカイブには新ランチャーがないため、
旧アーカイブに対してラッパーだけを変更しないでください。
今回、外部tapのFormula・公開済みアーカイブは変更していません。

各対象OSの受入では、案内を開くだけではブラウザーを開かないこと、ボタン操作で正しいHTTPS URLへ到達すること、
ブラウザーを起動できない環境でのエラー案内、画面の閉じる・再表示、翻訳、対象外配布での非表示を確認します。
openUrlの戻り値成功は起動要求の受付を示すもので、ページ表示の成功とは区別します。
