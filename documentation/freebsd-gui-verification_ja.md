# FreeBSDでのGUI操作確認

検証日: 2026-11-09（日本時間）。[構築記録](freebsd-virtualbox-setup_ja.md)のVirtualBox VM上で実施。

## 結果

Folimeldのメニュー、ツールバー、ファイルダイアログを実際に操作し、以下の範囲では正常に動作した。今回のGUI操作中にアプリの異常終了はなかった。

| 操作 | 確認結果 |
| --- | --- |
| PDF表示と選択 | 日本語PDFの8ページをサムネイル表示し、ページを選択できた |
| 別名保存 | 保存ダイアログと進捗表示を経て、新しいPDFへ保存できた |
| 右へ90度回転 | 選択ページの向きとサムネイルが変化した |
| 元に戻す・やり直し | 回転前後の状態へ戻せた |
| ページ移動 | 回転した先頭ページを2ページ目へ移動できた |
| 白紙挿入 | 選択ページと同じサイズの白紙を挿入し、全8ページから9ページになった |
| 白紙挿入の取り消し | 元に戻す操作で全8ページに戻った |
| 編集後の保存・再読込 | 保存後に「開く」ダイアログで同じPDFを選び、8ページ・変更後の順序・2ページ目の回転が維持された |

起動済みの文書には未保存の変更があったため、最初にその状態を検証用の別ファイルへ保存した。元のサンプルPDFへの上書きは行っていない。

保存先（ゲスト内）:

- 操作前: `/home/folimeld/Folimeld/build/freebsd-verification/gui-manual-before.pdf`
- 操作後: `/home/folimeld/Folimeld/build/freebsd-verification/gui-manual-after.pdf`

## 操作方法と保存結果の照合

Windowsのcomputer-useツールでVirtualBox内をマウス操作した。文字キーが同ツールからゲストに届かなかったため、保存名の入力のみVirtualBoxの `keyboardputstring` を使用し、入力された内容をGUIで確認してから保存した。アプリ内部APIを使った編集・保存ではない。

GUI操作完了後に保存済みファイルを読み取り、ページ数、各ページの内容ストリームのSHA-256、回転角度を照合した。

- 操作前のページ番号を基準に、操作後の順序は `2, 1, 3, 4, 5, 6, 7, 8`。
- 操作後の2ページ目のみ回転角度90度、ほかは0度。
- 内容ストリームは対応する操作前ページと一致し、ページ数は8。

[照合結果JSON](freebsd-verification/gui-manual-verification.json)と[再読込後の画面](freebsd-verification/gui-manual-after.png)を保存した。

## 確認範囲

今回は上記の基本操作を確認した。パスワード、画像フォルダー取り込み、フォーム付きPDF、保存失敗時の挙動、大容量PDFの負荷試験は、このGUI確認には含めていない。
このGUI確認時点では、既存テストで見つかったPyMuPDFのフォーム読み込み時の異常終了は未解決だった。後続作業で修正し、フォームPDFのGUI保存・再読込も確認した。詳細は [フォーム読み込み異常終了の修正](freebsd-forms-fix_ja.md) を参照。
