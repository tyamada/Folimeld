# Linux DEB amd64 0.3.5の追加GUI検証

2026-11-13（日本時間）。公開後の同一DEBを専用Ubuntu24.04.4 WSL2/WSLgで検証した。Debian/Kaliや通常デスクトップの追加機能合格を意味しない。[検証JSON](linux-deb-amd64-extended-verification-2026-11-13.json)。

- 導入済み0.3.5のELF SHA-256は公開時と一致。専用XDG/D-Bus内のGIO関連付けから日本語名PDFを開き、3ページの表示を確認。
- UbuntuのMozc 2.28は新しい環境のsymbol/composition_mode設定を受け付けなかった。試験専用設定のactive_on_launchを使い、nihongo→にほんご→日本語の変換・確定を実画面で確認。最初の設定エラーとibus engine設定終了1（照会はmozc-jp）を合格結果と区別した。
- 合成AES-256 PDFを認証して回転・別名保存。保存後の再認証と表示を確認。保存データは3ページ・回転[180,0,0]・日本語保持、誤パスワード拒否。入力素材は初期回転[90,0,0]で、新たに90度回転した。
- 合成PNG1枚のフォルダ取込と保存を確認。保存PDFは1ページ・画像1枚・中央RGB[0,0,255]。
- 試験素材は保存していたtar内の原本とすべてバイト一致。dpkg --verifyとAPT依存確認は管理ユーザーで成功。一般ユーザーでAPT確認を試した初回の失敗と、確認用Python環境の差を区別した。

既存の公開添付は公開時点の未再試験記録として保持する。本追記は公開済みバイナリの追加検証であり、再ビルド・差し替え・新規Releaseではない。通常ファイルマネージャーのダブルクリック、他IME、広い画像/暗号化設定、Debian/Kaliの追加機能は未検証。
