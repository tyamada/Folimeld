## 候補との厳密な対応

ステージした全686入力について、Git blobを直接読み出したSHA-256がrevision5対応ZIPの入力目録と一致した。改行フィルターでソースの実バイト列を変えないよう、raw blobをステージした。これにより通常の改行正規化を使ったコミット準備とは差分の見え方が異なる。

差分には改行のみの46パスと、内容変更28パス、追加ファイル群がある。Mac/Windows用spec等の多くは改行だけの差分で、機能変更ではない。候補に収録された再生成画像資産とLinux固有暗号依存記録も含むため、これはAlma公開ソースのスナップショット用ブランチであり、そのままmainへマージする案ではない。元の画像・他OS用記録は保持されている。

全ステージ対象・保持数・ハッシュは[ツリー検証JSON](linux-almalinux9-release-tree-2026-11-12.json)、内容変更と改行のみの分類は[変更分類JSON](linux-almalinux9-release-tree-change-classification-2026-11-12.json)へ保存した。
