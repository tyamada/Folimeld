# サンプルPDF

言語リストで「すべて」または各言語・地域を選べます。初期値はアプリの言語（指定がなければシステム言語）に合わせ、対応がなければ「すべて」です。表示順は「最新話から」（初期値）と「1話から」を選べます。下部には著作権者とCC BY 4.0のライセンスを常時表示します。

「ファイル → サンプルPDFを開く…」または未読込時の案内から、話数・言語地域・作品名・取得容量を確認して1冊を選べます。取得後は容量とSHA-256を照合してから開きます。全51冊の自動取得はしません。失敗時は再試行でき、取得中はキャンセルできます。

一覧取得・検証に失敗した場合は、前回の正常な一覧、同梱一覧の順に戻ります。同梱一覧は公開マニフェスト schema_version=1 のスナップショットです。初回取得にはインターネット接続が必要です。取得済みの検証済み原本は次回起動・オフラインでも再利用できます。

保存先は配布形式ごとのQt AppLocalDataLocation配下の `samples-v1` です。`originals` は検証済み原本、`opened` は開くたびに作成する編集用コピーです。通常の保存は編集用コピーに反映し、原本を変更しません。必要に応じて「名前を付けて保存」で利用者の保存先へ保存してください。自動的な全消去・過去コピー削除は行いません。元から開いていた文書に未保存の変更があれば、既存の保存確認を行います。

最新一覧は https://raw.githubusercontent.com/tyamada/manga-prompt-kit/main/releases/pdf-manifest.json を使用します。PDFは一覧の `new_download_url` に記載された固定Releaseから取得し、legacy・latest/downloadを使いません。HTTPSとGitHubの指定リポジトリ・既知のRelease資材配信先を検証します。認証情報は不要です。
