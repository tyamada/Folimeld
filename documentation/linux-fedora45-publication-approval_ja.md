# Fedora 45試験版の公開許可

2026-11-13。ユーザーは、Fedora45 amd64向け0.3.5試験版の公開質問へ「このFedora試験版を公開する」と回答した。

対象は専用ブランチ `release/fedora45-amd64-0.3.5`、タグ `fedora45-amd64-v0.3.5`、[公開計画](linux-fedora45-publication-plan-2026-11-13.json)の11添付（合計1,922,302,300バイト）。prerelease=true、make_latest=falseで公開する。既存配布物とmainの作業変更は保持する。

これは初回の公開保留指示に対する、このFedora試験版だけの明示的な解除である。mainへの実装マージ、他ディストリビューションの公開、既存配布物の置換・削除は対象に含まない。
