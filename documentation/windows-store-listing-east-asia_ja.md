## 韓国語（Korean / `ko-KR`）

### 短い説明（Short description）
PDF 페이지를 썸네일로 보면서 순서 변경·회전·삽입·삭제할 수 있습니다. 이미지 폴더에서 PDF 만들기도 지원합니다.

### 説明（Description）
Folimeld는 PDF 페이지를 썸네일로 확인하면서 직관적으로 정리할 수 있는 데스크톱 앱입니다. 문서의 페이지 순서를 바꾸거나 방향을 바로잡고, 다른 PDF에서 페이지를 추가할 수 있습니다. 모든 문서는 기기 내에서만 처리되며, 편집을 위해 PDF나 이미지를 개발자 서버로 전송하지 않습니다.

여러 페이지를 선택해 한 번에 이동·회전·삭제할 수 있으며, 저장 후에도 실행 취소(Undo)·다시 실행(Redo)을 사용할 수 있습니다.

JPEG·PNG·BMP·TIFF·WebP 이미지 폴더에서 새 PDF를 만들 수 있습니다. 이름이나 날짜순으로 정렬하고 불필요한 이미지를 제외한 뒤, 이미지 크기 또는 A4 페이지 크기를 선택할 수 있습니다. 다중 페이지 TIFF도 지원합니다.

문서 속성에서 PDF 버전, 페이지 레이아웃, 제본 방향(오른쪽 제본·표지 포함)을 설정하고 열기 비밀번호를 설정하거나 제거할 수 있습니다.

### 主な機能（Product features）
- 썸네일을 보면서 PDF 페이지 순서 변경
- 여러 페이지 일괄 이동·회전·삭제
- 다른 PDF 또는 빈 페이지 삽입
- 저장 후에도 사용 가능한 실행 취소 / 다시 실행
- 이미지 폴더에서 새 PDF 만들기 (JPEG, PNG, BMP, TIFF, WebP)
- PDF 버전, 페이지 레이아웃, 오른쪽 제본 및 표지 설정
- 열기 비밀번호 설정 및 제거
- Windows 11 x64 및 ARM64(Copilot+ PC 등) 네이티브 지원

### このバージョンの新機能（What's new — 1.0.6.0）
- 한국어 번역(비밀번호 및 샘플 PDF 기능 포함)을 완비하고 번체 중국어(대만·홍콩·마카오) 지원을 추가했습니다.
- Store 업데이트 확인 및 업데이트 버튼, 서포터 배지 UI를 포함합니다.

## 繁体字中国語（Chinese (Traditional) / `zh-TW`・`zh-HK`・`zh-MO`）

### 短い説明（Short description）
透過縮圖直覺整理 PDF 頁面：重新排序、旋轉、插入與刪除，並支援從圖片資料夾建立 PDF。

### 説明（Description）
Folimeld 是一款可透過縮圖預覽輕鬆整理 PDF 頁面的桌面應用程式。您可以調整頁面順序、修正方向，或從其他 PDF 插入頁面。所有文件皆在您的裝置本機處理，不會將 PDF 或圖片傳送至開發者伺服器。

支援選取多個頁面一次進行移動、旋轉或刪除，儲存後仍可使用復原（Undo）與重做（Redo）。

可從包含 JPEG、PNG、BMP、TIFF 或 WebP 的圖片資料夾建立全新 PDF，依名稱或日期排序、排除不需要的圖片，並選擇符合圖片大小或 A4 頁面尺寸，亦支援多頁 TIFF。

在文件屬性中可設定 PDF 版本、頁面配置與裝訂方向（含右裝訂與封面設定），並支援設定或移除開啟密碼。

### 主な機能（Product features）
- 透過縮圖預覽重新排列 PDF 頁面
- 多選頁面一次移動、旋轉或刪除
- 插入其他 PDF 或空白頁
- 儲存後仍可使用的復原與重做
- 從圖片資料夾建立 PDF（JPEG、PNG、BMP、TIFF、WebP）
- 設定 PDF 版本、頁面配置、右裝訂與封面
- 設定或移除 PDF 開啟密碼
- 原生支援 Windows 11 x64 與 ARM64（Copilot+ PC 等）

### このバージョンの新機能（What's new — 1.0.6.0）
- 新增繁體中文（台灣、香港、澳門）介面與自動語言偵測，並完善韓文與簡體中文翻譯。
- 內建 Microsoft Store 更新檢查與更新按鈕，以及支持者徽章 UI。
