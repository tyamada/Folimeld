# サンプルPDF第4話の取得確認（2026-11-28）

## 結果

Windows 11 x64開発PCのmainソースで、最新版JSONの52冊を取得し、日本語第4話を選択・ダウンロードしてFolimeldの8ページのサムネイル表示まで確認した。コア機能の修正は不要だった。初回取得確認ではアプリコード・版を変更しなかった。後続の出典リンク修正は下記に区別して記録する。配布物作成・Release公開・Store提出・試験PC更新・WACK・Hosted API比較は行っていない。

## 環境と範囲

- 初回GUI確認の対象コミット: `7b4347a599337f951d387dc2c9d434316891c58c`。
- 代表環境はWindows 11 x64ネイティブ実行。検証用Python・Qt環境を利用。個別端末の識別情報・生ログは公開しない。
- 初回検証対象の`folimeld/__init__.py`は0.3.5表記。Storeのパッケージ版や公開版のアプリ表示版と混同しない。
- 起動したのはMainWindowとSampleDialogを利用する検証ハーネス。専用INI・専用サンプル保存領域を指定し、通常設定や既存PDFを使用しない。正式配布ランチャー／インストール済みStoreアプリの受入試験ではない。
- エミュレーターではなく、このWindows x64 PCのネイティブGUIで確認。Windows ARM64、Linux、macOS、BSDの実動作は今回未確認。

## 実装確認

- `sample_catalogue.parse_catalogue`はschema_version=1、1～2000件、話数1～10000、PDF最大256MiB。51冊／第3話までの固定上限はない。
- 取得には各項目の`new_download_url`を使用し、トップレベルの旧fixed_tag／release_urlを使ってPDF URLを組み立てない。第4話の別タグURLも許可規則を満たす。
- オンライン一覧を検証してからキャッシュを更新する。通信・検証失敗時のみキャッシュ／同梱一覧へフォールバックする。
- 同梱一覧は51冊・1～3話のまま。これはオフライン用スナップショットであり、最新項目を取得するにはオンライン更新が必要。古いキャッシュしかなく通信もできない場合、第4話を表示できるとは保証しない。

## 確認した流れ

1. 専用キャッシュに元の同梱51冊一覧を用意。
2. MainWindowのshow_samples経路でオンライン一覧取得。52冊に更新、日本語／最新話からでep4_ja、ep3_ja、ep2_ja、ep1_jaを確認。
3. 実画面から第4話の行と「選択したPDFを取得／開く」を操作。
4. 取得完了100％、別作業コピーを開いたことと8ページ／8サムネイルを確認。表紙・本文サムネイルの実描画を画面で確認した。8ページすべての細部を目視検査したものではない。
5. 閉じる操作で正常終了、終了コード0。
6. 保存された原本と開いた作業コピーを独立してサイズ・SHA-256照合。両方一致。
7. 通信を拒否するテスト条件で、検証済み原本を再利用。最新版52件のキャッシュも保持できることを確認。
