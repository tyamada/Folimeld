FOLIMELD · PDF PAGE EDITOR

Folimeld for macOS

macOS 15 or later · Apple Silicon · Homebrew

What you can do

  • Preview PDF pages as thumbnails; rearrange, rotate, insert and delete pages.
  • Create a PDF from an image folder and save a separate copy.
  • PDF and image contents are processed locally. Available features depend on the distributed edition.

Install with Homebrew

For Apple Silicon (arm64) on macOS 15 or later. Run in Terminal with Homebrew already installed.

brew install --build-from-source tyamada/tap/folimeld
folimeld

Homebrew prepares Python 3.14 and an isolated dependency environment. This is not the legacy standalone app distribution. Intel Macs are outside this distribution’s verified scope.
