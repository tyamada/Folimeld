Folimeld プライバシーポリシー

対象は Microsoft Store で配布する Windows 版 Folimeld です。公開者は Takuma Yamada です。本ポリシーは Folimeld が Microsoft Store で初めて公開された日に施行します。

PDF と画像の処理

Folimeld は、利用者が選んだ PDF や画像と、入力した閲覧パスワードを、表示・編集・保存のため端末内で処理します。画像の並べ替えにはファイル名や作成・更新日時を使用します。PDF や画像の内容を開発者のサーバーに送信する機能はありません。閲覧パスワードは処理中のメモリで扱い、アプリの設定には保存しません。

端末内の設定、一時データ、ログ

言語、表示設定、最後に開いたフォルダーのパスは端末内に保存します。編集履歴や保存・変換の途中のデータは、メモリや一時ファイルに保持することがあります。不要になった履歴や中間データは通常の処理で解放・削除します。強制終了などでは一時ファイルが残る場合があります。保存した文書は利用者が指定した場所に残ります。同期フォルダーに保存した場合は、そのサービスの設定に従います。

端末内のエラーログには例外情報やファイル名・パスが含まれる場合があります。ログを開発者へ自動送信する機能はありません。

Microsoft Store と外部サービス

初回 Store 版ではアプリ内の応援購入と関連する商品・ライセンス照会を無効にしています。Folimeld 独自の利用者アカウント、広告、利用状況解析、自動クラッシュ報告はありません。Microsoft Store や Windows が行う処理には Microsoft のプライバシーに関する説明が適用されます。

お問い合わせ

サポートおよびプライバシーに関するお問い合わせは tyamada.support@gmail.com へご連絡ください。受信したメールアドレスと本文は、回答と問題の調査に使用し、専用メールボックスで管理します。対応終了から90日を目安にメールと添付ファイルを削除します。削除を希望する場合は同じ窓口へご連絡ください。機密文書、個人情報を含む PDF、パスワードは送らないでください。

Folimeld Privacy Policy

This policy applies to the Windows version of Folimeld distributed through the Microsoft Store. The publisher is Takuma Yamada. This policy takes effect on the date Folimeld is first published in the Microsoft Store.

PDF and image processing

Folimeld processes the PDFs and images you select and the document passwords you enter on your device to display, edit, and save documents. It uses file names and creation or modification dates to sort images. The app has no feature that sends PDF or image contents to the developer’s servers. It handles document passwords in memory during processing and does not save them in app settings.

Local settings, temporary data, and logs

Folimeld stores language and display preferences and last-used folder paths on your device. It may keep editing history and intermediate save or conversion data in memory or temporary files. The app normally releases or deletes this data when it is no longer needed. Temporary files may remain after an abnormal termination. Saved documents remain at the locations you choose. If you save to a synchronized folder, the service’s settings apply.

Local error logs may include exception details, file names, and paths. The app does not automatically send these logs to the developer.

Microsoft Store and external services

The initial Store release disables in-app supporter purchases and related product and license queries. Folimeld has no developer-operated user accounts, advertising, usage analytics, or automatic crash reporting. Microsoft’s privacy information applies to processing by Microsoft Store or Windows.

Contact

For Folimeld support and privacy inquiries, contact tyamada.support@gmail.com. We use your email address and message to respond and investigate the issue, and we keep correspondence in a dedicated support mailbox. We aim to delete messages and attachments within 90 days after the inquiry is closed. You can request deletion by contacting the same address. Please do not send confidential documents, PDFs containing personal information, or passwords.
