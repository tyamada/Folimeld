Folimeld — Microsoft Store edition

A PDF page editor for Windows 11. Microsoft Store installation, usage, support and privacy.

Get Folimeld from Microsoft Store

The Japanese and US Microsoft Store listings were checked. Both show November 26, 2026 as the last update and announce German, Spanish, French and Portuguese translations and expanded worldwide availability. Publisher: Takuma Yamada. Check the Store for pricing and in-app purchase availability.

Microsoft Store — JapanMicrosoft Store — United States

What you can do

  • Preview PDF pages as thumbnails; rearrange, rotate, insert and delete pages.
  • Create a PDF from an image folder and save a separate copy.
  • PDF and image contents are processed locally. Available features depend on the distributed edition.

Requirements and edition

  • PC, Windows 11 version 22000.0 or higher. The published corresponding-source Release targets Store version 1.0.7.0 (app 0.3.10, x64 / ARM64). The Store web listings do not display a numeric package version or CPU list. The currently delivered package version and CPUs, completion of worldwide rollout, and installation or upgrades on each CPU were not verified in this check.
  • An MSIX desktop app installed through Microsoft Store. No separate Python or uv installation or routine elevated launch is needed.
  • The main window of the earlier Store version 1.0.1.0 was verified as Per-Monitor V2; this is separate from hardware DPI verification of the current version. This does not establish coverage of every scaling and multi-monitor combination.
  • A separate distribution channel from the GitHub Desktop and uv previews. Do not transfer preview validation results to the Store edition; consult the instructions and features for each edition.

Install, launch, update and remove

  • Use a Store link above, verify the product and publisher, and install. An internet connection is required to obtain or update the app.
  • Launch Folimeld from the Start menu. Explorer’s Open with command can also open a PDF in Folimeld.
  • Check Microsoft Store’s Library for updates. Availability follows the Store’s distribution status.
  • Remove it through Windows Settings → Apps → Installed apps. PDFs you saved are separate user files. Back up your settings and documents beforehand.

Privacy and data

Selected PDFs, images and document passwords are processed on your device. The app does not automatically send document contents or error logs to the developer. User-initiated sample PDF downloads contact the public distribution source. See the policy for local settings, temporary files, logs and support correspondence.

Limitations and troubleshooting

  • Rendering, forms or saved output can differ from the originating application for some PDFs. Keep the original and verify a separately saved copy.
  • In 1.0.1.0, some thumbnails have been reported to shift after inserting a PDF. This public-information check does not establish whether the current Store-delivered version resolves it. If affected, contact support with the version and steps.
  • If the app does not start, check Windows and Store updates and restart Windows. Back up documents and settings before repair or reinstallation.
