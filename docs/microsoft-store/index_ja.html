FOLIMELD · PDF PAGE EDITOR

Folimeld — Microsoft Store版

Windows 11向けPDFページ編集アプリ。Microsoft Storeからの導入・使い方・サポート・プライバシー。

Microsoft Storeから入手

Microsoft Storeの日本・米国の掲載を確認しています。 公開者：Takuma Yamada。価格やアプリ内購入の提供状況はStoreの表示をご確認ください。

Microsoft Store（日本）Microsoft Store（米国）

できること

  • サムネイルでPDFのページを確認し、並べ替え・回転・挿入・削除。
  • 画像フォルダーからPDFを作成し、別名で保存。
  • PDF・画像の内容は端末内で処理。機能の範囲は配布版により異なります。

対応環境と配布版

  • Windows 11 バージョン22000.0以降・PC。Folimeld 1.0.8.0（アプリ0.3.11、x64／ARM64）はMicrosoft Storeで公開済みです。Partner CenterでSubmission 7の配信完了を確認しました。StoreのWeb掲載には数値版・CPU一覧が表示されません。全市場への配信完了と各CPUでの導入・更新は未確認です。
  • Microsoft Storeから導入するMSIXデスクトップアプリです。Python・uvの事前導入や、管理者としての通常起動は不要です。
  • 旧Store配信版1.0.1.0のメインウィンドウはPer-Monitor V2を確認しています。現行版のDPI実機確認とは区別しています。すべての倍率・複数画面の組み合わせを検証したものではありません。
  • GitHubのDesktop・uv試験配布版とは別の配布経路です。試験版の検証結果をStore版へ流用せず、機能・導入手順は各版の案内をご確認ください。

導入・起動・更新・削除

  • 上のMicrosoft Storeリンクから製品名と公開者を確認して導入します。入手や更新にはインターネット接続が必要です。
  • スタートメニューのFolimeldから起動します。エクスプローラーの「プログラムから開く」でもPDFを開けます。
  • 更新はMicrosoft Storeのライブラリから確認できます。更新の提供時期はStoreの配信状態に従います。
  • 削除はWindowsの「設定」→「アプリ」→「インストールされているアプリ」から行います。自分で保存したPDFは別管理です。設定や文書は事前にバックアップしてください。

プライバシーとデータ

選択したPDF・画像・文書パスワードは端末内で処理します。文書内容やエラーログを開発者へ自動送信する機能はありません。利用者の操作によるサンプルPDFの取得時には公開配布元へ通信します。設定・一時ファイル・ログ、問い合わせメールの扱いは次のポリシーをご確認ください。

既知の制限・困ったとき

  • 一部のPDFでは表示・フォーム・保存結果が元アプリと異なる場合があります。原本を保持し、別名で保存して結果を確認してください。
  • 1.0.1.0ではPDF挿入後の一部サムネイルの位置ずれが報告されています。現行Store配信版での改善状況は今回の公開情報確認だけでは判定していません。発生時は版と手順を上記窓口へご連絡ください。
  • 起動しない場合はWindowsとStoreの更新、再起動を確認してください。修復・再インストール前には文書と設定をバックアップしてください。
