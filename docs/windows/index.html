FOLIMELD · PDF PAGE EDITOR

Folimeld for Windows

Windows 11 · Microsoft Store and preview editions

What you can do

  • Preview PDF pages as thumbnails; rearrange, rotate, insert and delete pages.
  • Create a PDF from an image folder and save a separate copy.
  • PDF and image contents are processed locally. Available features depend on the distributed edition.

Microsoft Store edition (recommended)

Version 1.0.1.0 for Windows 11 x64 is free in Japan and the United States. No separate Python or uv installation is required.

Settings and validation scope

Store, Desktop, source + uv and uv tool editions use separate settings/log profiles. This does not mean every combination has passed coexistence or upgrade testing. The x64 0.3.6 Wheel passed fresh installation, PDF opening, Close and normal exit; fresh three-worker observation and rollback remain unverified for that candidate.
