Folimeld for Windows

Windows 11 · Microsoft Store and preview editions

What you can do

  • Preview PDF pages as thumbnails; rearrange, rotate, insert and delete pages.
  • Create a PDF from an image folder and save a separate copy.
  • PDF and image contents are processed locally. Available features depend on the distributed edition.

0.3.7 preview.1: download sample manga PDFs

Published November 2026. Choose one book through “Open sample PDF…” in the File menu or empty-document prompt. Includes a language filter defaulting to the app/system language, newest-first/episode-one-first ordering, and copyright/CC BY 4.0 attribution. Downloads are SHA-256 verified and opened as separate working copies.

PDFs are not bundled; the first download requires internet access. You can also use the sample PDF catalogue. Store version 1.0.1.0 does not include this download feature; this is not a Store update. ARM64 edition has also been updated to 0.3.7 preview.1.

0.3.7 preview.1 installation and all ten assets · SHA-256 checksums

Settings and validation scope

Store, Desktop, source + uv and uv tool editions use separate settings/log profiles. This does not mean every combination has passed coexistence or upgrade testing. For x64 and ARM64 0.3.7, fresh installation, online catalogue retrieval, one Japanese manga download/verification, eight-page display, Save As, reopen and exit were checked. All public assets matched their sizes and SHA-256. Fresh three-worker PID observation, upgrade/rollback, Store coexistence, and mixed DPI remain unverified for this candidate.
