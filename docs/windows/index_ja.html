FOLIMELD · PDF PAGE EDITOR

Folimeld Windows版

Windows 11・Microsoft Store版と試験配布版

できること

  • サムネイルでPDFのページを確認し、並べ替え・回転・挿入・削除。
  • 画像フォルダーからPDFを作成し、別名で保存。
  • PDF・画像の内容は端末内で処理。機能の範囲は配布版により異なります。

Microsoft Store版（通常利用向け）

Windows 11 x64向け1.0.1.0を日本・米国で無料公開しています。Pythonやuvの事前導入は不要です。

Store専用ページ・プライバシー・サポート

上級者向けのGitHub試験配布

Store版の更新ではありません。Desktop版は未署名のインストーラーです。uv版にはuvと依存関係の導入が必要です。OSの安全機能を無効にせず、ReleaseのSHA-256・手順・未確認事項を確認してください。

設定と確認範囲

Store・Desktop・ソース＋uv・uv tool版は専用の設定・ログ領域を使用します。ただし、すべての版の併存・相互更新を検証したものではありません。x64 0.3.6 Wheelの新規導入・PDF表示・閉じる・正常終了は確認済みですが、この候補での3ワーカー観測や旧版復帰は未確認です。
