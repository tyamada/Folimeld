0.3.7 preview.1：サンプルPDFマンガを取得

2026年11月公開。ファイルメニューまたはPDF未読込時の案内の「サンプルPDFを開く…」から、1冊を選んで取得できます。言語フィルター（初期値はアプリ／システム言語）と最新話から／1話からの表示順を備え、著作権・CC BY 4.0を表示します。取得したPDFのSHA-256を検証し、編集用の別コピーを開きます。

PDF本体は同梱せず、初回取得には通信が必要です。サンプルPDF集約ページからも取得できます。Store版1.0.1.0にはこの取得機能は含まれず、今回の公開はStore版の更新ではありません。 ARM64版も0.3.7 preview.1へ更新されています。
