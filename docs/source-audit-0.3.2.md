# 0.3.2 対応ソース調査

調査日: 2026-09-09。対象はリポジトリ内の`releases/ubuntu/`にある配布物です。
公開サイトやStoreへ実際にアップロードされたファイルとの同一性は未確認です。

上記の版は各パッケージから実行ファイルを取り出し、その中の
`licenses/Installed-packages.txt`を読み取った結果です。現在の仮想環境の版を転記したものではありません。

deb内の実行ファイルは現在の`dist/folimeld`と一致します。Snap内の実行ファイルとは異なります。
手元の`build/linux-build.log`はPython 3.12環境の記録を含むため、これをdebのビルド記録と
扱うことはできません。Snapには`stage-packages`由来のネイティブライブラリも含まれます。

## ソースとの対応について

配布物のGit履歴には`2ab6177`（deb/Snap追加）と`23d1ff0`（Ubuntu 22.04対応）があり、
調査時点で`v0.3.2`タグはありません。これらは**配布物を登録したコミット**であり、
実際にビルドした作業ツリーがそのコミットと一致していた証明にはなりません。
現在のHEADには、既存バイナリのビルド後に追加したサポーター画像なども含まれます。
現在のHEADのZIPを既存0.3.2の対応ソースとして公開しないでください。

## 取得と確認の状況

- PyMuPDF 1.28.2とPillow 12.3.0のソース配布物をPyPIから取得し、公開SHA256を照合しました。
- PyMuPDF 1.28.2の`setup.py`は`version_mupdf = '1.28.2'`を指定しています。
  このPyMuPDFソース配布物にはMuPDFソースアーカイブが同梱されていません。
- PySide6 6.11.2のPyPIメタデータにはソース配布物がありません。
  Qt公式サーバーから同版のPySideソースとQt全体のソースを取得し、公式SHA256と照合しました。
- MuPDF 1.28.2のソースを`setup.py`が指定する公式URLから取得し、SHA256を記録しました。
  このファイルについては公開元の独立したチェックサムとの照合は行っていません。
- 取得ファイルとURL・SHA256の記録はローカルの`dist/source/dependencies-0.3.2-linux/`に保存します。
  ダウンロード済みであっても、wheel内のネイティブライブラリとの対応確認が終わった意味ではありません。
  取得記録の控えは [依存ソース取得記録](source-downloads-0.3.2.json) にあります。

## 残作業

1. 既存の各バイナリについて、当時のソース保存物・ビルド環境・wheelの入手元と変更点を確定する。
   特定できない場合は、記録可能なソースから新しい版をビルドして今後の配布を置き換える。
   新版を提供しても、旧版に関する必要なソース提供が自動的に解決するわけではない。
2. Qt/MuPDF等のネイティブライブラリと内包コード、Snap追加パッケージの必要なソース・告知を揃える。
   上流の同じ版番号のアーカイブだけで、配布wheel固有のパッチやビルド条件まで揃ったと判断しない。
3. 依存ソースとFolimeldソースからのビルド手順を検証し、各配布物の横に取得リンクを公開する。
4. Windows/macOSおよびStoreにある配布物は別途調査する。この調査の対象に含めない。

今後のビルド記録・ソースZIP生成は [ライセンスと配布](license-distribution.md) を参照してください。
